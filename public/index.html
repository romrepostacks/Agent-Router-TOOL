        Quick questions

        On a provider usage-limit error, the selected fallback is retried. If no fallback is selected, another installed provider is picked automatically. Account-wide limits may still prevent a retry.

        Keyboard shortcut

        Shared-skill limit

        −1 means unlimited, 0 sends no skills, and a positive number sets the maximum. Always-on skills are considered before task-selected skills.

        Always-on shared skills

        Approved skills are included automatically with every provider, up to the limit above. You can approve any number; when the limit is smaller, approvals are used first in the order selected.

        Add a skill from GitHub

        Paste a link to a skill on GitHub: its SKILL.md file, its folder, or the repo. Scan reads it and checks for risky instructions. Nothing is installed until you choose Install.
