        Shared-skill limit

        −1 means unlimited, 0 sends no skills, and a positive number sets the maximum. Always-on skills are considered before task-selected skills.

        Always-on shared skills

        Approved skills are included automatically with every provider, up to the limit above. You can approve any number; when the limit is smaller, approvals are used first in the order selected.
